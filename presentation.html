Employee Features

สิทธิ์พนักงาน

📷 Face Scan Check-in/out

  • กล้องจับใบหน้าอัตโนมัติ
  • ถ่ายรูปเก็บเป็นหลักฐาน
  • Face threshold: 0.75
  • Manual press (ไม่ auto-scan)

📍 GPS Enforcement

  • ต้องอยู่ในรัศมี office (200m)
  • ทั้ง check-in และ check-out
  • Geolocation API

📅 Employee Menu

  • สรุปวันนี้ (work hours, status)
  • 快捷 links ไปหน้าต่างๆ
  • Shift calendar

📄 Leave Request

  • ขอลาย้อนหลัง/ล่วงหน้า
  • หลายประเภท (sick, annual, personal)
  • แนบเอกสาร/เหตุผล

⏱ OT Request

  • ขอ OT หลังเวลาเลิกงาน
  • เฉพาะพนักงานที่มีสิทธิ์ (has_ot)
  • supervisor + HR approve

🏠 WFH Request

  • ขอ work from home
  • Saturday 1 วัน/เดือน
  • Auto-approve สำหรับ MD+

Live Demo Flow

สาธิตการใช้งาน

Step 1: Employee Check-in

  • 1. เปิดหน้า Kiosk (/employee)
  • 2. Face Scan → Verify face
  • 3. เลือก action (check-in / check-out)
  • 4. ระบบบันทึก + ถ่ายรูป + GPS

Step 2: Employee Dashboard

  • 1. Login → ดู menu (/employee/menu)
  • 2. ดูสรุปวันนี้ (work hours, status)
  • 3. ขอลา/OT/WFH
  • 4. ดูประวัติย้อนหลัง

Step 3: HR Dashboard

  • 1. Login admin
  • 2. ดู Dashboard → มีคนเข้างานกี่คน
  • 3. Company breakdown (NTC, ETC, ETECH, STC)
  • 4. Late / On-time statistics

Step 4: Reports & Export

  • 1. ไปหน้า Reports
  • 2. Export PDF → ได้รายงานพร้อม work hours
  • 3. Bulk payslip export
  • 4. Audit log
